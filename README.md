# girls

一份关于**亲密关系中沟通方式**的调研，按证据强度分层组织。

核心特点是**每条结论都标了证据等级**——哪些有同行评议研究支撑、哪些只是作者判断，分得很清楚。

👉 **从 [`docs/README.md`](docs/README.md) 开始读。**

## 三条主要结论

1. **回应好消息比回应坏消息更重要**【有研究支撑】——大多数沟通建议都在教怎么安慰人，但研究显示，对方分享好事时你怎么接，更能预测关系质量。
2. **追问会显著增加好感，而且人们普遍低估它**【有研究支撑】——用真实速配约会数据验证过。
3. **MBTI 那一层基本没有实证支撑**——本调研中所有"XX型喜欢什么"的内容都是待验证的假设，不是结论。要用人格分类，依恋类型可靠得多。
