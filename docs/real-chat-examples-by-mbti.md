# 日常聊天语料清单（按 MBTI 分）

> 定位：**仿真日常聊天语料**，不是采样的真实聊天记录。
> 判断标准是"这句发出去像不像人话"，不是"这句从谁手机里抄的"。
> 用法：当对照清单看，不是当台词背。

---

## 0. 先说清楚三件事

1. **这些是写出来的，不是采集的。** 我没有真人聊天数据集。所有例子是按真实中文聊天的语言特征（句长、语气词、标点习惯、信息密度）构造的，力求"像"，但不宣称"是"。
2. **网上的"高情商话术"大多是反面教材。** 搜一圈会看到大量"12种幽默话术""25句撩人回复"——那套东西的语感恰恰是最容易被识别为油腻的：押韵、排比、有明显的套路结构。**真实感的核心是不工整**。
3. **MBTI 在这里是分组标签，不是科学结论。** 同一型的人差异极大。这份清单的正确读法是"这类风格的人通常吃这一套"，不是"她是 INFP 所以必须这么聊"。

## 1. 语感规则：像真人 vs 像话术

这一节比后面所有例子都重要。**同一个意思，语感对了就成立，语感错了全废。**

### 1.1 像真人的六个特征

| 特征 | 说明 | 例 |
|---|---|---|
| **短，且分条发** | 一次一个意思，不写小作文 | `我靠` / `刚看到` / `那你现在还好吗` |
| **句号是攻击性的** | 日常聊天很少用句号，用了显得冷 | `好` 比 `好。` 温和十倍 |
| **有废话和噪音** | 真人会打断自己、改口、发无意义的音 | `诶不对` / `等下` / `啊算了` |
| **具体名词** | 说得出店名、线路、剧名，才像真的经历过 | `六号线那个出口` 而不是 `地铁站` |
| **自嘲多于自夸** | 真人靠掉价换亲近 | `我刚把咖啡洒键盘上了，人生完蛋` |
| **允许不接话** | 有些话不用回应，笑一下就过 | `哈哈哈哈` `草` |

### 1.2 像话术的七个特征（避雷）

| 特征 | 例（都是反面） | 问题 |
|---|---|---|
| **工整/押韵/排比** | `你是我平淡生活里唯一的星光` | 一眼假 |
| **无信息量的试探** | `在吗` / `睡了吗` / `猜猜我在干嘛` | 把成本推给对方 |
| **过早的亲密称呼** | 第三天开始叫 `宝` `老婆` | 越界 |
| **小作文式关心** | 三百字的"多喝热水注意身体"长段 | 表演性 >  真实性 |
| **说教** | `我跟你说这事你就应该……` | 降维打击对方 |
| **连环追问** | `你在干嘛？吃饭了吗？跟谁？` | 像查户口 |
| **秒回 + 长回复的组合** | 她两句，你八行 | 信息密度失衡 |

### 1.3 一条通用的长度纪律

**回复长度不超过她上一条的 1.5 倍。**
她发两句你回八行，无论内容多好，压迫感都已经产生了。

### 1.4 全场景通用的万能句

这三句几乎不会错，任何类型都适用：

```
「你现在是想吐槽，还是想一起想想办法？」   ← 她抱怨时
「那你当时什么感觉？」                     ← 想让她多说
「我记得你说过……」                        ← 任何时候，杀伤力最大
```

## 2. 通用日常场景：好 / 坏对照

不分类型，这些是基本盘。

### 场景 1：开启话题

```
❌ 在吗
❌ 猜猜我在干嘛
❌ 早上好，新的一天也要元气满满哦

✅ 刚路过你上次说的那家面包店，队排到马路上了
✅ 突然想起来，你上次说的那个剧叫啥来着
✅ 我今天差点把工牌刷进食堂的垃圾桶
✅ 你那边下雨了没，我这边突然黑成半夜
```
> 规律：**开场要自带信息和钩子**。"在吗"是把开场成本转嫁给她。

### 场景 2：她说"好累"

```
❌ 那你就早点睡啊
❌ 我今天比你还累，加班到十点
❌ 那你要不换个工作？我觉得你现在这个不适合你

✅ 累哪种，身体累还是那种"再干也没意义"的累
✅ 今天是不是又是那个人的破事
✅ 嗯。
   那你现在啥都别干，躺着。
✅ 听着就烦。你先说，我不打断
```
> 规律：**先分类，别急着解决**。"累哪种"这个问法几乎无敌。

### 场景 3：约见面

```
❌ 你什么时候有空？
❌ 有空一起吃个饭呗
❌ 你想吃什么都行，我都可以

✅ 周六下午有个市集，走路十分钟就到，去不去
✅ 那家你说想去的，我看周三人少。周三行吗
✅ 我周末大概率在家躺着，你要是也无聊就来
```
> 规律：**给具体选项，别抛开放题**。"你想吃什么都行"看似体贴，实际是把决策成本全推给她。

### 场景 4：关心

```
❌ 多喝热水
❌ 注意身体啊，健康最重要，你要好好照顾自己……（三百字）

✅ 药吃了没
✅ 我到楼下了，粥放前台了，你别下来
✅ 降温了，你那件外套是不是还在公司
✅ 明天几点的会？我怕你又忘了定闹钟
```
> 规律：**关心要落到一个可执行的动作上**，否则就是表演。

### 场景 5：她不回消息

```
❌ ？
❌ 怎么不理我了
❌ 你是不是生气了 / 我是不是说错什么了
❌ （连发五条）

✅ （什么都不发，等）
✅ （隔一天，发一个新话题，完全不提上一条）
✅ 看你朋友圈就知道你这两天忙疯了，不用回我
```
> 规律：**沉默不是需要被处理的问题**。追问是最快的减分方式。

### 场景 6：意见不合

```
❌ 你这个想法不对
❌ 行行行你说得都对
❌ 我是为你好

✅ 我不太同意，但你先说完
✅ 我可能想的不一样——我是这么看的……你觉得呢
✅ 这个我真的说不过你，我回去再想想
```

### 场景 7：道歉

```
❌ 对不起嘛~
❌ 我错了我错了我错了
❌ 对不起，但是你当时也……

✅ 昨天是我不对，我不该那样说。
✅ 我想了一晚上，我确实是急了。跟你没关系。
✅ 对不起。我下次会先问你。
```
> 规律：**别加"但是"**，加了整句作废。

### 场景 8：夸她

```
❌ 你好漂亮
❌ 你真的好聪明啊
❌ 你是我见过最好的女生

✅ 你刚才讲你项目的时候语速一下就快了，你其实挺喜欢它的吧
✅ 你怎么每次都能一句话把事说清楚，我写三段都写不明白
✅ 那个决定挺狠的，我可能做不到
```
> 规律：**夸具体行为和内在特质，别夸外貌和结果**。

### 场景 9：收尾 / 晚安

```
❌ 晚安好梦，愿你有个甜甜的梦~
❌ （突然消失）

✅ 睡了，明天见
✅ 你赶紧睡，明天还要早起
✅ 好，不聊了，你困了我看得出来
```

## 3. 十六型 × 日常聊天语料

每型给：**语感基调 → 日常例句（按场景）→ 会冷场的说法**。

---

### INFP

**基调**：慢、软、不评判、允许沉默。信息量可以少，但不能有压迫感。

```
开话题
  今天路过一片特别夸张的晚霞，拍糊了但还是想发你
  这首歌我循环一下午了（直接发歌，不加评价）
  你上次说的那本书，我看到第三章了。有点难受

她说累 / 情绪低
  嗯。
  不用现在说，我在
  你不用解释，我知道那种感觉
  你今天说话跟平时不太一样。不用回我，就是想让你知道我发现了

约见面
  周末我大概会去那个旧书店泡一下午，你要是想出门就一起
  不去也完全没关系，我就是想着你可能喜欢

关心
  你今天吃东西了吗（不追问，问一次就够）
  我把你那个待办记下来了，你要是忘了我提醒你

玩笑 / 轻松
  我今天在便利店纠结了十分钟选哪个饭团，最后两个都买了，然后都不好吃

她沉默 / 不回
  （不催。隔一天）诶，昨天那家店我去了，跟你说的一样难吃

夸
  你形容东西的方式很奇怪，但每次都特别准
  你好像总能注意到别人注意不到的地方

会冷场的说法
  ✗ 你想太多了
  ✗ 这有什么用啊
  ✗ 你倒是说话啊
  ✗ 你就是太敏感了
```

---

### ENFP

**基调**：快、高频、接得住跳跃。允许话题一分钟换三次。

```
开话题
  我刚想到一个特别蠢的问题：如果猫会说话，它第一句会说啥
  卧槽你看这个（直接甩链接）
  紧急提问：菠萝披萨到底算不算食物

她说累
  烦死了。谁惹的，我帮你骂
  今天不许干正事了，来，说点没用的
  你这几天太满了，明天翘个班？我陪你翘

约见面
  周六，那个新开的，我已经想好点什么了，你只需要出现
  临时起意：今晚出来吃个宵夜？半小时内到

接梗 / 玩笑
  哈哈哈哈哈哈你怎么想出来的
  那按你这个逻辑，我们是不是应该直接搬去南极
  行，那我们就当没这回事（配合她的胡说八道）

她沉默
  你要是在忙就别回，我自己在这儿自言自语
  （发一个新的、更好玩的话题，不提旧的）

夸
  你刚才说到一半停住的那个想法，其实才是最有意思的，说完啊
  跟你聊天永远不知道下一句是啥，太爽了

会冷场的说法
  ✗ 你能不能说重点
  ✗ 这不现实
  ✗ 你怎么老是三分钟热度
  ✗ （消失一整天不回）
```

### INFJ

**基调**：一对一、有厚度、说到做到。她在意的是一致性，不是热度。

```
开话题
  有个问题想听你的角度：……
  我最近在想一件事，想了两天没想明白

她说累
  是那种被榨干的累，还是被人耗掉的累
  你是不是又在替别人处理情绪
  你不用当那个懂事的人，起码在我这儿不用

约见面
  周六下午，安静点的地方，就我俩。你定时间
  人多的场合我就不叫你了，你不喜欢

关心
  你上次说的那个事，后来怎么样了（长期回调 = 核心杀伤力）
  我记得你这周有个挺重要的会。今天是吧

深聊
  你觉得人是会变的，还是只是环境变了
  你有没有那种，明明是自己选的，但还是觉得亏欠的时刻

夸
  你总在读别人的情绪。那你自己的呢，有人读吗
  你说话很少，但每句都是想过的

会冷场的说法
  ✗ （答应了没做到 —— 这是最严重的）
  ✗ 你想那么多干嘛
  ✗ 大家都这样啊
  ✗ 忽冷忽热
```

### ENFJ

**基调**：温暖、有回应、给足反馈。最怕的是"嗯""好"这种句号式回复。

```
开话题
  你上次帮我出的那个主意，真的有用，跟你汇报一下
  有个事想问你，你比较懂人

她说累
  你又在照顾所有人了是不是
  这次别管他们了，你先歇
  你做了这么多，有人跟你说过谢谢吗

约见面
  周六我安排好了，你什么都不用管，人来就行
  这次换我请，不许抢

关心
  你今天从早到晚一个会接一个会吧，吃饭了吗
  我看你朋友圈了，那个活动办得真好，累坏了吧

反馈（对她最重要）
  你说的我听进去了，我改了
  真的有用，我按你说的做了，成了

夸
  你安排了所有人，唯独没安排你自己
  你身上有种让人放松的能力，这个真的很少见

会冷场的说法
  ✗ 嗯 / 好 / 哦（单字回复是慢性死亡）
  ✗ 你管那么多干嘛
  ✗ （不评价她的付出，默认她应该做）
  ✗ 关系不明不白拖着
```

### INTP

**基调**：低频也没关系、逻辑好玩、别逼她处理情绪。

```
开话题
  冷知识：香蕉是浆果，草莓不是。世界是错的
  问你个问题，你觉得"随机"真的存在吗
  我今天debug了四个小时，最后发现是个空格

她说累
  哦，那你歇着，我不烦你
  需要我干嘛吗，不需要就当我没说
  （不追问情绪，给空间）

约见面
  周六我在家，你要是也没事就过来，各干各的也行
  那个展要不要去，不去也行，我随便问问

抬杠 / 智力互动
  你这个前提就有问题
  等下，你刚才那个推论跳了一步
  行，你说得有道理，我收回

她不回消息（关键）
  （三天没回也不问。她再出现时）诶，回来了
  不用回我，我知道你在思考人生

夸
  你这个想法很怪，但我想了半天没找到漏洞
  跟你聊天不用解释前提，省事

会冷场的说法
  ✗ 你怎么不回我消息
  ✗ 你是不是不在乎我
  ✗ 你能不能正常一点
  ✗ 别想了，做就完了
```

### ENTP

**基调**：互怼、反驳、玩梗。顺着她说 = 无聊。

```
开话题
  我要挑战一个你肯定不同意的观点：……
  今天听到一个特别弱智的说法，跟你分享一下

她说累
  谁啊，报名字，我给你分析他哪儿蠢
  行，今天你负责骂，我负责递词

抬杠（核心玩法）
  不是，你这话逻辑不通
  你刚才自己打自己脸了知道吗
  哈哈哈哈行吧，这局算你赢
  你这属于诡辩，但我喜欢

玩笑
  你这人怎么这样（笑）
  我收回刚才所有夸你的话
  跟你说话我得开个录音，怕我改天被反咬

约见面
  周六，我赌你不敢去
  出来，我有个特别离谱的想法要当面说

夸
  跟你吵架比跟别人聊天有意思多了
  你是少数几个我说不过的人

会冷场的说法
  ✗ 你说得对（每次都这样 = 死）
  ✗ （认真生气，接不住玩笑）
  ✗ 你能不能严肃点
  ✗ 太无聊、太安全的回复
```

### INTJ

**基调**：直给、别绕、尊重她的时间和计划。

```
开话题
  直接说：周六想约你。地方我选好了，你只要说行不行
  有个事，两句话说完：……

她说累
  需要我做什么，说具体的
  你要是想自己待着，我就不打扰了。要人的话我在

约见面
  周六下午两点，那家咖啡馆，靠窗。行就行，不行你说时间
  （提前三天约，不临时改）

沟通习惯
  结论先说：不行。原因是……
  我改主意了，因为发现了新的信息
  这个我不确定，我查一下再回你

关心
  你那个项目下周截止吧，需要我帮你挡点什么吗
  别熬了，边际收益已经是负的了

夸
  你判断这个事的时候比我快，而且是对的
  你不解释你的决定，我也不用问，这点很省心

会冷场的说法
  ✗ 猜猜看
  ✗ 你觉得呢（把决策全推回去）
  ✗ 临时改计划
  ✗ 无意义的寒暄轰炸
```

### ENTJ

**基调**：果断、有方案、能扛事，但不怕她比你强。

```
开话题
  两个方案，你选一个：A 周六，B 周日。我都可以
  有件事我想听你判断，你比我看得准

她说累
  这事我处理，你别管了
  你现在需要的是有人替你做决定：今晚不加班，回家

约见面
  周六七点，位置发你了，我订好了
  （不问"你想吃什么"，直接给）

意见不合
  我不同意，理由三个：……你反驳
  你这个点我没想到，算你对

关心
  你这周排太满了，砍掉一个
  身体是资源，你现在在透支

夸
  你不用在我面前赢
  这件事你处理得比我干净

会冷场的说法
  ✗ 都行 / 随便 / 你决定
  ✗ 拖延、没跟上、答应了做不到
  ✗ 你一个女生这么强干嘛
  ✗ 说了半天没有结论
```

### ISFJ

**基调**：稳、具体、可预期。她要的是"不会突然消失的人"。

```
开话题
  刚路过你公司楼下那家，想起你说过喜欢他家的豆浆
  今天降温了，你出门加衣服了吗

她说累
  你今天是不是又一个人收尾的
  你先歇着，剩下的明天再说
  你做的那些别人没说，我看见了

约见面
  周六下午两点，还是老地方？我提前定位子
  （提前约，准时到，不放鸽子）

关心（她最吃这个）
  我到了，你慢慢来，不着急
  今天路上堵，我可能晚十分钟，先说一声
  药我买好放你桌上了

夸
  每次聚会最后收拾的都是你
  你记得所有人的口味，那你自己的呢

会冷场的说法
  ✗ 忽冷忽热、消失几天再出现
  ✗ 临时放鸽子
  ✗ 突然的大惊喜（她会焦虑）
  ✗ 当着别人的面开她玩笑
```

### ESFJ

**基调**：高频、及时、明确。暧昧不清是最大的伤害。

```
开话题
  早，今天降温，多穿点
  刚看到这个觉得你会喜欢（高频小分享）
  今天在公司发生了个特别搞笑的事，听我说

她说累
  谁啊，我听你说
  你今天做的事我都知道，太不容易了
  （及时回，别隔几小时）

约见面
  周六我朋友聚会，一起去？我想介绍你认识
  这周三我们那个小群吃饭，你来吧

回应频率（核心）
  在的
  刚在开会，现在能聊了
  （不秒回也要报备，最怕已读不回）

夸
  你一进来气氛都不一样了
  你是那种把所有人都照顾到的人

会冷场的说法
  ✗ 已读不回 / 隔一天才回
  ✗ 关系不明说、不见朋友、不公开
  ✗ 说她朋友坏话
  ✗ 冷淡的单字回复
```

### ISTJ

**基调**：清楚、诚实、说到做到。承诺兑现比任何情话都重要。

```
开话题
  周六那个事我确认了，十点开始，我十点前到
  上次说的那个东西我买了，明天带给你

她说累
  今天几点下班的
  这周你已经加了四天班了，明天必须早走

约见面
  下周六下午三点，那家店，我订了。有变化我提前两天告诉你
  （不放鸽子，不迟到，不临时改）

日常
  我到了
  这个我不确定，我查清楚再告诉你
  我说过会做，我做了

关心
  你三个月前说想看那个展，票买了，周六
  你手机充电线上次断了，我买了一根，一样的型号

会冷场的说法
  ✗ 说了不做
  ✗ 夸大、吹牛
  ✗ 迟到、临时变卦
  ✗ 我尽量吧 / 应该可以 / 再说吧
```

**基调**：高效、有担当、别废话。讨论"怎么做"比讨论"感觉"更让她放松。

夸

会冷场的说法

  ✗ 挑战她的判断但拿不出依据

## 4. 自查清单

发出去之前过一遍：

- [ ] 这条比她上一条长了 1.5 倍以上吗？→ 删
- [ ] 有句号结尾的短句吗？→ 大概率显冷
- [ ] 里面有"在吗""睡了吗"吗？→ 换成带信息的开场
- [ ] 是不是连着问了两个以上问题？→ 砍到一个
- [ ] 夸的是外貌/结果，还是具体行为/内在特质？→ 后者
- [ ] 她在说情绪，我在给方案吗？→ 先分类情绪
- [ ] 道歉里有"但是"吗？→ 删掉，整句作废
- [ ] 她没回，我准备追问了吗？→ 别
- [ ] 这句话工整、押韵、像段子吗？→ 一眼假，重写
- [ ] 我答应过的事做到了吗？→ 这条比上面所有条加起来都重要

---

## 5. 最后：所有类型都成立的三件事

1. **具体 > 华丽**。"六号线那个出口"胜过"我在地铁站"。
2. **做到 > 说到**。记住她随口说的一件事然后真的做了，抵得过一千句情话。
3. **节奏 > 浓度**。一直热情会腻，一直冷淡会散。真实的关系是有起伏的。
