# 恋爱沟通方式调研

一份关于"什么样的说话方式在亲密关系里更有效"的调研，**按证据强度分层组织**。

---

## 证据分级

这是这份调研最重要的东西。每一条结论都标了等级，**不要跨级引用**。

| 级别 | 含义 |
|---|---|
| **【A】** | 有同行评议研究支撑，且本次核到了原始出处（期刊、卷期、样本量） |
| **【B】** | 有研究支撑，但只核到二手来源，或研究本身样本小 / 存在学术争议 |
| **【C】** | 平台方公布的行为数据。样本量大但**无法独立核实**，且场景受限 |
| **【D】** | **没有任何数据支撑**。是作者的语言判断或从上面几级做的推论 |

大白话版本：
- 【A】可以拿去跟人争论
- 【B】可以信，但要说"有研究显示……不过样本不大"
- 【C】当作线索，不当作结论
- 【D】**这就是一个人的意见**，跟你在小红书上看到的没有本质区别，只是我把它标出来了

## 如果只看三条

**1. 回应好消息比回应坏消息更重要。**【A】

大多数"恋爱沟通"内容都在教你怎么安慰人。但 Gable 等人 2006 年发在 JPSP 的研究发现，**对积极事件的回应方式，比对消极事件的回应方式更能预测关系质量**。她说"我方案过了"时你怎么接，比她说"我好累"时你怎么接更要紧。详见 [`02`](02-responding-to-good-news.md)。

**2. 追问会显著增加好感，而且人们意识不到这一点。**【A】

Huang 等人 2017 年（JPSP）用真实速配约会数据发现，追问更多的人拿到第二次约会的概率更高。机制是"被感知的回应性"。关键是**追问**（顺着对方刚说的往下问），不是首次提问。而且实验显示人们**预料不到**多提问会让自己更讨喜——所以这是个被系统性低估的技巧。

**3. MBTI 这一层基本没有实证支撑。**【B】

这份调研里所有"XXXX 型女生喜欢什么"的内容，**都是没有数据的**。学界不用 MBTI 做关系研究，因为它预测力不够。真要用人格分类，依恋类型和大五人格都比它可靠得多。MBTI 部分保留在 [`04`](04-mbti-heuristics.md) 里，但请当作**待验证假设**，不是结论。

## 一句话总结这份调研的性质

**真正扎实的部分是跨类型的通用规律（回应好消息、追问、具体性）；按人格类型细分的部分是没有依据的猜测。**

前者可以直接用，后者只能当灵感。

推论：**你多半不需要"确定对方是哪一型"**——最有效的两条对所有人成立。
真要判断，看行为，别看标签。见 [`06-how-to-tell.md`](06-how-to-tell.md)。

## 已知缺口

诚实列出这份调研做不到的事：

- **没有中文语境的句式级数据。** 现有的中文婚恋调查（如北师大 × 小红书 2026 年那份，2823 份问卷）停留在婚恋观层面，不到"哪种开场白回复率高"这么细。
- **没有做过任何一手调查。** 所有内容来自文献检索和作者判断。
- **引用的研究以西方和东南亚样本为主**，跨文化外推有风险。
- **交友软件的数据来自平台自己发布的博客**，无法独立核实，且只覆盖"陌生人首次接触"这一个场景。
